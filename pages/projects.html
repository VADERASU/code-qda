    From a recording to a coded transcript

    1. Upload the recording. In a project, click Upload at the top of the Files list. Most audio formats work (.m4a, .mp3, .wav, .ogg, .opus).
    2. Transcribe it. The recording appears under Recordings. Click Transcribe and say how many people speak. It runs on this server and can take a while for a long interview. You can close the page meanwhile.
    3. Verify it. Open the new transcript and click Verify against audio. Listen to the passages flagged for review and correct what the transcription got wrong.
    4. Code it. Back in the transcript, select a passage and apply a code.

    Try it in your Sandbox first, with a recording you're allowed to use there. Nobody else can see it. Its practice interview is already partly coded so you can try coding right away.

    New project

    You'll own it and can add people who already have an account here. Everyone in a project can upload transcripts and audio and code them together.
